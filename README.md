# TimeFlow

**看见时间，掌握生活。**

TimeFlow 是一款面向 macOS 的智能时间管理应用，帮助你记录时间、理解时间结构，并建立更有意识的生活方式。

## 核心功能

- 智能时间记录
- 时间结构可视化
- 目标与计划管理
- AI 自然语言交互
